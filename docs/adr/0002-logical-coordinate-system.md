# ADR-0002: 224×256の論理座標を基準とする

- Status: Accepted
- Date: 2026-10-23

## Context

Unity Transformをゲームルールへ直接使うと、表示倍率・カメラ・素材のPPUが移動量や命中判定に影響します。原作相当の位置や寸法を仕様として扱うために、表示から独立した座標基準が必要です。

## Decision

224×256の仮想画面、左下原点の論理ピクセル座標をゲームルールの基準にします。描画時にUnity座標へ変換し、Transformを論理位置の正として読み戻しません。

## Consequences

位置・寸法・当たり判定を表示設定から独立して調整できます。論理座標とUnity座標の変換は表示側で一貫させる必要があります。基準解像度の採用だけで、個別の位置・速度・素材寸法が原作どおりと確定するわけではありません。
